# Immersed support

For a playback, subtitle, dictionary or accessibility bug, [open a GitHub issue](https://github.com/Somamill/immersed-community/issues/new/choose). Include the app version, macOS version, a public video link if relevant, and what happened. Avoid sharing private account details or credentials.

For Store edition help, private feedback, privacy or security requests, email [max@miller-max.com](mailto:max@miller-max.com). Do not post personal information in a public GitHub issue. The project is an independent open-source app; YouTube video availability depends on its owner and YouTube.

Questions, ideas, or spotted a bug? [Email Max](mailto:max@miller-max.com). Feedback is always welcome.
